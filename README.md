## Laboratorio 01

### Comparativa de desarrollo de aplicación sin código

El primer laboratorio aborda el análisis de diferentes herramientas de desarrollo de aplicaciones sin código, con el objetivo de seleccionar una herramienta adecuada para desarrollar rápidamente una aplicación para la matrícula de estudiantes en los laboratorios.

El trabajo incluye:

- Introducción a conceptos relacionados con el desarrollo rápido de aplicaciones.
- Análisis de diferentes herramientas de desarrollo sin código.
- Cuadro comparativo de las herramientas.
- Descripción de la aplicación propuesta.
- Selección y justificación de la herramienta más adecuada.
- Conclusiones del análisis.
- Referencias utilizadas.
